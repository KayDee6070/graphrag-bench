# M8 controlled extraction examples

These three original fictional passages exercise two affirmative relationships and a negated statement. They are development examples, not research papers or held-out benchmark data. The prompt's separate Helix/Comet/Tundra/Marsh examples are recorded in `configs/llm-extraction.toml`.

The intended positive claims are Orion `USES` Nova and Nova `EVALUATED_ON` Harbor. The negated Mirage statement should not become a positive `EVALUATED_ON` assertion. Inspect actual model outputs rather than assuming these intended claims were extracted correctly.

Ingestion includes Markdown files, so use the dedicated `texts` directory in commands to exclude this README from model inputs.
